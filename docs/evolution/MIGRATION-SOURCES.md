# Desktop import guide: source references

The source chooser offers file filters and export guidance. It does not identify the exporting application, change the import parser, or establish compatibility with every version or export option. The existing import preview remains the review step. An ADIF export is not a complete backup; retain the original log and check profiles, confirmations, attachments and additional fields.

Primary documentation consulted:

- [Log4OM 2 user manual](https://www.log4om.com/l4ong/usermanual/Log4OMNG_ENU_ADV.pdf): ADIF export.
- [DXKeeper QSO export](https://www.dxlabsuite.com/dxlabwiki/QSOExport): ADIF export from the displayed log.
- [Logger32 official site](https://www1.logger32.net/program.html): ADIF backups and documentation.
- [Ham Radio Deluxe log export](https://support.hamradiodeluxe.com/support/solutions/articles/51000052695-exporting-log-files): log export formats.
- [MacLoggerDX manual](https://www.dogparksoftware.com/MacLoggerDX/Manual/Pages/menus.html): export and selection options.
- [N1MM Logger+ contest operation](https://n1mmwp.hamdocs.com/getting-started/operating-a-contest/): ADIF export.

These references do not replace tests with actual exports from each application and version. Native settings, profiles, attachments and complete backup restoration are not implied by an ADIF import. Existing N1MM database parsing has synthetic test coverage; actual vendor files and cross-platform interoperability remain to be checked.
