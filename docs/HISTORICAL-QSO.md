# Historical QSO entry

Open **Historical QSO entry** from the desktop menu. Enter the UTC date and time explicitly, along with the callsign, band or frequency, and mode. The dialog starts with no current time, radio frequency, mode or default signal reports. It does not tune the radio. Review every field against the source; selecting **Use selected station profile details** is optional and applies the active profile, so use it only if those details describe the historical operation. Without it, the QSO is unassigned to a profile unless its fields are entered explicitly.

**Log & keep** retains the date, band, frequency, mode, power and entered program references for the next QSO. It clears the callsign, per-contact information, signal reports and time. If the next entered UTC time is earlier than the last saved time on the same date, choose **Next UTC day** explicitly or confirm that the earlier time really belongs to the same date. Nothing advances the date automatically. The rule applies within the current open dialog and compares the immediately preceding successful save; it is not a chronological audit of the whole log. **Clear** clears the date and per-contact fields. A closed/reopened dialog starts a new entry session.

Historical records use the existing manual QSO path and retain `APP_DECOLOG_ENTRY_CONTEXT=HISTORICAL` in ADIF extras. They do not inherit active rover or activation data, infer split frequencies from the current rig, invoke callbook completion or broadcast as live contacts. The save does not immediately schedule the automatic QSL-service handler; existing background service settings and cloud synchronisation may still act on records subsequently. Manual duplicate entries remain allowed, so check the source and log for duplicates. A selected profile may contain current rather than historical values; the operator is responsible for choosing an appropriate profile and verifying those values.

The feature has been tested with isolated synthetic records, programmatic UI and a loopback rigctld split-rig fixture, not radio hardware or RF. Physical keyboard/mouse, other desktop platforms and large historical-entry sessions remain to be checked.
