# Local QSL image OCR

From an existing QSO's **Received QSL archive**, open **Read image with local OCR**, select a local image and choose **Read image**. The application starts a separately installed Tesseract executable locally with the English (`eng`) language model and reads its TSV output. It searches the process PATH and, on macOS, `/opt/homebrew/bin` and `/usr/local/bin`. Tesseract and its model are not bundled; install them separately from a trusted source and make the executable available to the desktop app. The [upstream command-line documentation](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html) describes the TSV interface and [Tesseract's source is Apache-2.0 licensed](https://github.com/tesseract-ocr/tesseract/blob/main/LICENSE); its dependencies and model data have their own distribution requirements.

The display shows raw text and words below a heuristic 75/100 confidence threshold, not calibrated probabilities. Review every character against the original image, including words above the threshold. The OCR result does not update a QSO, create a contact, attach an image, or grant QSL/award credit. Use the existing **Import scan or image** action separately to attach the original to the selected QSO. File selection does not upload the image. The selected file is read by the local engine; do not modify or replace it during recognition. Results are held in memory and disappear when the app exits.

This initial implementation accepts locally readable images up to 32 MB and 40 million pixels, with each dimension at most 12,000 pixels. PDF OCR, language selection, field extraction, candidate matching, multi-QSO review, persistent acquisition and undo are not yet implemented. Cancel stops the local process; a 90-second limit and 4 MiB result limit bound a run. Errors are reported without retaining OCR output. Engine installation, language data and platform packaging need separate verification on Windows and Linux. Two synthetic printed layouts are not evidence of handwriting, faded cards or arbitrary QSL quality.
