## 2026-11-22 — G05 guarded recovery backend

Schema 13 adds an import-time fingerprint of the complete QSO row, per-service QSL state, attachment metadata and enrichments. It is calculated and recorded within the QSO import savepoint. The durable `undoLatestImport` operation opens a transaction per journalled QSO, checks its local ID, persistent UUID, revision and fingerprint, and soft-deletes only unchanged records. Already-deleted, missing/replaced, changed and failed records are counted separately; a later retry does not repeat completed deletions. Schema-12 journal entries have no baseline and are conservatively skipped for review. A profile change or service update that modifies the stored row can produce a conservative skip. ## 2026-11-23 — G07 bounded derived numeric fields

A numeric custom field can now define a bounded arithmetic formula using numeric constants, `{CUSTOM_FIELD}` references, parentheses and `+ - * /`. Evaluation follows dependencies deterministically; a missing input leaves dependent values empty, while division by zero and non-finite results prevent logging. Input numbers use the current Qt locale with grouping disabled; computed values use C-locale decimal text with 15 significant digits.
