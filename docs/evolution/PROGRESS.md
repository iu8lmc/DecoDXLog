## 2026-11-22 — G02 mode classification and station scope

Marathon previously treated AM and USB as digital and rejected CW-R for CW. The selector now uses the shared mode grouping, handles DSB as phone, and excludes an empty mode from single-mode category filters. A/B fixture: before, phone selected 0 instead of AM and USB; after, phone selects both, digital selects FT8 only, and CW selects CW-R. The existing general mode grouping treats unrecognised non-empty modes as data, so official eligibility is still not established.

Export retains the preview's edition/category/entity limit/profile and is disabled if those controls change. `QSaveFile` protects an existing JSON export from partial replacement.
